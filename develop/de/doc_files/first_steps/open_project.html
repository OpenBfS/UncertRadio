2.3. Existierendes Projekt einsehen¶

Um die Arbeitsweise des Programms kennen lernen zu können, empfiehlt es sich, einige bereits fertige Projekt-Beispiele anzusehen. Wie man dazu vorgeht, wird hier kurz aufgezeigt; die Abfolge der Schritte und der zu klickenden Buttons und TABs (Register) entspricht im Wesentlichen auch der Vorgehensweise bei der Erstellung eines eigenen Projekts.

Tipp

Eine Führung des Benutzers erfolgt in der Statusleiste am unteren Ende des UncertRadio-Fensters, in dem Feld ganz rechts.

Laden Sie eine vorhandene Projektdatei (Erweiterungen txp oder csv) eines Messproblems über den Button , wodurch alle Berechnungen durchgeführt werden und schließlich der TAB “Resultate” sichtbar wird.

To proceed, follow these steps:

  • Select the TAB Verfahren for comments on that procedure

  • Select the TAB “Gleichungen”

  • Click the button „Load symbols from equations“

  • Klicken Sie auf den Button „Load symbols from finalized symbol table”

  • Button „Alles übernehmen” betätigen -> damit wird das TAB “Values, Uncertainties” bedienbar

Next, review the equations and the table of symbols, then:

  • Select the TAB “Values, Uncertainties”

  • Click the Button „Calculation of uncertainties“ to enable the TAB „Unsicherheiten-Budget“

  • Review the details in the uncertainty table

  • Select the TAB „Unsicherheiten-Budget“ to view the uncertainty budget of the output quantity

  • Wählen Sie den TAB “Resultate” aus, um alle Ergebnisse einschließlich Erkennungsgrenze und Nachweisgrenze anzusehen

Alternativ können Sie eine Monte-Carlo-Simulation der Berechnungen starten, indem Sie auf den Button „Start” klicken.

Um die Projektdatei zu schließen, das nächste Projekt zu laden oder das Programm zu beenden, verwenden Sie die folgenden Optionen:

  • File – Quit program to terminate the program

  • Load the next project by following the same steps as above

  • Schließen Sie die Projektdatei über die Option oder beenden Sie das Programm: Datei – Programm beenden.

Achtung

Wenn man beim Durchgehen der verschiedenen Programmteile Werte geändert hat, sollte man das Projekt nicht speichern, wenn das Programm danach fragt, da sonst die Projektdatei verändert würde.

Durch Mausklick innerhalb von Tabellen bzw. im Gleichungsfenster ist auch das Scrollen in ihnen mit dem Mausrad möglich.
