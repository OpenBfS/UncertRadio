5.5. 7.6 Hinweise zur linearen Kurvenanpassung mit dem „allgemeinen Fall“ der Least squares-Anpassung (WTLS)¶

Der sogenannte „allgemeine Fall“ der Methode der kleinsten Quadrate (WTLS) wird in UncertRadio dann verwendet, wenn die \(X_{i}\left( t_{k} \right)\)-Werte des Modells eigene Unsicherheiten und ggf. auch Kovarianzen aufweisen. Es ist das einzige dem Autor bekannte und zugängliche Verfahren, das die Einbeziehung von Unsicherheiten und Kovarianzen der \(X_{i}\left( t_{k} \right)\)-Werte erlaubt.

Zur Durchführung der Berechnung werden Matrix-Routinen aus der Datan-Library verwendet (in Fortran 90 konvertiert), die Haupt-Subroutine des Verfahrens ist LSQGEN:

Siegmund Brandt: Datenanalyse. Mit statistischen Methoden und Computerprogrammen; 4. Auflage. Spektrum, Akademischer Verlag, Heidelberg-Berlin, 1999.

Although the model continues to be linear with respect to the fitting parameters, WTLS requires an iterative procedure. Therefore, starting values of the fitting parameters are obtained from a preceding call to the simpler LSQ routines.

Unfortunately, the mathematics used in the routine LSQGEN is rather complicated, which is the reason that a description cannot yet be given here. Another routine precedes LSQGEN in UncertRadio which assembles the input data in a special form which is required by LSQGEN. Measured net counting rates \(Y\left( t_{k} \right)\) and the different \(X_{i}\left( t_{k} \right)\ \)values are combined in one common vector y; the same applies to the uncertainties and covariances of the \(Y\left( t_{k} \right)\) and \(X_{i}\left( t_{k} \right)\) values, which results in a common input covariance matrix cy. The rank of the vector \(\mathbf{y}\) and of the quadratic matrix cy may easily increase to a significant value. If, for example, a LSC measurement with 3 counting channels is considered and 10 measurements are done, one obtains:

3x10 = 30 values \(Y\left( t_{k} \right)\) (10 values for each of the channels A, B and C)

3x3x10 = 90 values \(X_{i}\left( t_{k} \right)\) (3 values \(X_{i}\left( t_{k} \right)\) associated with each of the values \(Y\left( t_{k} \right)\))

Somit beträgt der gesuchte Rang 30+90=120. Dies bedeutet, dass die Eingangs-Kovarianzmatrix eine 120x120-Matrix ist, wodurch sofort plausibel wird, dass die iterativ arbeitende Routine LSQGEN durchaus zeitaufwändig werden kann.

Hinweis zur Berechnung von Erkennungs- und Nachweisgrenze:

Wie bei der Beschreibung der LSQ-Mathematik soll der Ergebnisvektor der anzupassenden Parameter mit \(\mathbf{y}\) bezeichnet werden.

The special output quantities to be considered here refer to the component L of the result vector \(\mathbf{y}\) of the fitted parameters, \(y_{L}\), and its uncertainty \(u\left( y_{L} \right)\), which is iterated until \(y_{L}\) and \(u\left( y_{L} \right)\) fulfil the terminating condition of the iteration. \(y_{L}\) is then replaced by one new value \(y_{L}^{'}\ \)determined by the iteration. Using this one, one can calculate new values of the gross counting rates of the decay curve, where L=1 was set without losing generality:

\(R_{b,i}^{'} = \left( R_{0,i} + R_{bl} \right) + y_{1}^{'} \cdot X_{1}\left( t_{i} \right) + y_{2} \cdot X_{2}\left( t_{i} \right) + y_{3} \cdot X_{3}\left( t_{i} \right)\) .

Daraus folgt die Unsicherheits-Funktion (Standardunsicherheit) der Bruttozählrate:

\(u\left( R_{b,i}^{'} \right) = \sqrt{R_{b,i}^{'}/t_{m,i}}\) .

Die Nettozählraten der modifizierten Abklingkurve, d.h. die \(Y'\left( t_{k} \right)\), lauten:

\(R_{n,i}^{'} = R_{b,i}^{'} - R_{0,i} - R_{bl}\) ,

woraus sich die Diagonalelemente der geänderten Kovarianzmatrix ergeben:

\(var\left( R_{n,i}^{'} \right) = \frac{R_{b,i}^{'}}{t_{m,i}} + var\left( R_{0,i} \right) + var\left( R_{bl} \right)\),

während die nicht-diagonalen Elemente unverändert bleiben.

With these modified values and uncertainties of the net counting rates the evaluation for the output quantity is repeated yielding the new uncertainty value \(u\left( y_{1}^{'} \right)\). Now, the convergence criterion can be tested; if it is not yet fulfilled, the next iteration step is initiated by determining the next iteration value \(y_{1}^{''}\) from the pair \(y_{1}^{'}\) and \(u\left( y_{1}^{'} \right)\).
